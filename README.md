# TCP Client-Server Chat Application

## Project Overview

Developed a TCP Client application using C programming and Linux Socket Programming. The application establishes a connection with a server and enables message exchange between the client and server over a TCP network.

## Technologies Used

* Programming Language: C
* Operating System: Linux (Ubuntu)
* Communication Protocol: TCP
* Networking: Socket Programming
* Compiler: GCC

## Features

* TCP Socket Creation
* Client-Server Connection
* IP Address Configuration
* Message Transmission
* Message Reception
* Continuous Message Exchange

## Networking Concepts

* Socket Programming
* TCP Communication
* IPv4 Addressing
* Client-Server Architecture
* `socket()`
* `connect()`
* `send()`
* `read()`

## Connection Details

* IP Address: 127.0.0.1
* Port Number: 8080
* Communication: TCP

## Compilation

```bash
gcc client.c -o client
```

## Execution

```bash
./client
```
